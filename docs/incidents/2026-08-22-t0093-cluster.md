# T-0093: a 56-minute hold on ghost text, a piped watcher, and three smaller traps

**Date:** 2026-08-22 · **Card:** T-0093 · **Instance:** shepherd-collie

## What happened

1. **Suggested prompt read as a human draft.** An idle worker's input box showed `❯ Empty shepherds is fine, degraded says why - keep going`. That was Claude Code's own suggested next prompt, ghost text — but every snapshot source (`visible`, `recent`, `recent-unwrapped`, `detection`) renders a suggestion identically to typed input, and nothing distinguishes them. Shepherd read it as Saket's draft, refused to prompt the worker so as not to append to it, escalated, and held a finished worker idle for 56 minutes for nothing.
2. **Piped watcher.** `herdr agent wait ... 2>&1 | head -3` reports **`head`'s** exit status, so a timeout arrived looking like exit 0 — indistinguishable from a genuine `blocked` hit. An earlier "returns early after ~35 minutes" measurement came from such a pipe and was withdrawn: unpiped, `--timeout 3600000` ran ~67 minutes and exited 1 with `{"error":{"code":"timeout"}}` as documented.
3. **`agent wait` does not wait for an agent to appear.** Against a pane whose agent herdr had not yet detected it returned `{"error":{"code":"agent_not_found"}}` immediately, so R3's post-launch readiness wait raced the agent's own startup.
4. **Trust-folder dialog.** A brand-new project directory parked the worker on `Is this a project you created or one you trust?` with no output on `--source recent`.
5. **Sentinel inside a paragraph.** A worker that wrote *about* `SHEPHERD: done` mid-paragraph had that text recorded as a claim.

## What changed

Saket's ruling (2026-08-22): **shepherd is in control of the worker pane and prompts it whenever it judges it should, even with a human apparently present; only Saket specifically saying stand down changes that.** Text in a box is never a reason to hold a task — lead with a separator if a prompt might append to something real; the cost of a wrong nudge is one line, the cost of a wrong hold is unbounded. Watchers are armed bare, never piped; `scripts/watch.sh` reads herdr's stderr from a file. The readiness wait is retried, or `pane get` polled until `agent` is populated. The trust dialog is a routine permission prompt (its caret trap is in [2026-09-02-trust-dialog-caret.md](2026-09-02-trust-dialog-caret.md)). `hooks/worker-stop.sh` matches the sentinel only on its own line and records the last one in the turn (fixed 2026-08-23). The rollover watchdog likewise treats text after `❯` as no refusal, since it cannot tell ghost text from a draft.

## Where the rule stands

Adapter Gotchas (one line each), adapter R5 (never pipe), adapter R10 (ghost text), `docs/protocols.md` § Status protocol (the sentinel), memory `shepherd-controls-worker-panes`.
