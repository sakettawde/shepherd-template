# Project registry

One row per project directory. `shepherd-init registry <code-dir>` adds rows;
`onboarded: yes` is set by the **onboard** skill once the project has a card in
`registry/projects/<slug>.md` and a working agreement. Keywords route a thought
to a project — enrich them by hand as you learn what the operator calls things.
